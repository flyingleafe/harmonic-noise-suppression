### 2.1 Candidate 1 — the model that is actually being implemented

Physical model, per rig, clip `c`, rotor `r`:

$$f_{\text{actual},r}(t) = f_{\text{raw},r}(t-\delta_r) + b_{c,r} + \nu_r(t)/(2\pi)$$
$$d\nu_r = -\lambda_r \nu_r\,dt + \sqrt{2\lambda_r\sigma_r^2}\,dW_r,\qquad d\theta_r = \nu_r\,dt$$
$$d\epsilon_{rk} = \sqrt{2D_r}\,dW_{rk}$$
$$\Phi_r(t) = 2\pi\!\int_0^t\! \big[f_{\text{raw},r}(s-\delta_r)+b_{c,r}\big]\,ds + \theta_r(t),\qquad
x_m(t)=\sum_{r,k}A_{mrk}(t)\cos\!\big[k\Phi_r(t)+\epsilon_{rk}(t)+\alpha_{mrk}\big]+u_m(t)$$

- **One** OU shaft state `ν_r`, its integral `θ_r`, **shared across all orders and all microphones**.
- **One scalar `D` per rig** — *not* `D_{rk}`, no per-order free diffusion, no order law.
  Units: phase rad²/s. **No hidden `k` scaling** unless explicitly stated.
- `λ`, `σ` are **rig-shared** and **frozen** for candidate 1 (moment-initialized, then held fixed).
  If they are genuinely unidentifiable, report that — do **not** fabricate a "measured" value.
- `b_{c,r}` is a **per-clip random effect** with a proper prior and a population/recording mean.
- Gauge: `θ_r(t_0)=0`; initial `ν_r` stationary; mean OU stationary-zero in law.
- **No second carrier-correction spline, ever.** The per-frame carrier correction *is* the posterior
  `ν_r`. (See defect D1.)
- Existing source harmonic power profile, floor and speed law reused; **one recording-level gain
  shared across regimes** (a free per-clip gain would absorb the entire speed law).
- No tonebank/noise split. No spatial stochastic extensions beyond the existing fixed mic
  response/floor.

**Candidate-1 fitting procedure (this is the whole thing):**

1. Complex harmonic phase-increment **moments** on a *preregistered* isolated high-SNR order
   support (SNR/isolation gate fixed **before** estimates) → initialize and numerically estimate
   rig `λ`, `σ`; initialize scalar `D` from residual moments. These moment data are **initializers
   and diagnostics only**; they **must not** re-enter as a second likelihood factor, and there is
   **no** separate phase loss stacked on the spectral loss. The diagonal/GLS treatment is an
   **approximation** — do not call it exact; use diagnostic covariance and block variation.
2. **One** joint ordinary **PyTorch Adam** plug-in / composite **MAP** over: per-clip bias,
   dense-grid shared `θ`/`ν`, scalar `D`, existing line/floor powers, tied speed law.
   One exact Gaussian integrated-OU state prior. **No EM, no Kalman filter, no particle method,
   no per-harmonic `ε` latent inference, no dense smoother.**
3. Overlap temperature / prior weight calibrated separately on planted/baseline data and then
   **frozen**; frame count is never evidence.

**Complexity budget:** three rig dynamic parameters (`λ`, `σ`, `D`), one shared carrier path,
ordinary Adam, moment initialization. Nothing else unless a *named acceptance criterion* fails.

**Fix — state the single exact finite-window expectation once, and both of its branches:**

$$E|X(f)|^2=\iint w(t)w(s)\,

**D3 — Frame-centre atom approximation (within-window integration).**
The complex observation currently factors a nominal within-window atom from a single frame-level
residual `exp{i(kθ_{r,n} + ε_{rk,n})}`. That is exact **only** if the residual phase is constant

`μ_{mnq} = Σ_{rk} h_{mrk,q} Σ_{j∈window(n)} w_{nj} A_{rk,j} exp{ i[ kΦ0_{rj} + kθ_{rj} + ε_{rkj} − 2πf_q t_j ] }`.

**D5 — False exact `O(K)` Kalman claim.**
§6.1.6's callout claims the rank-one-plus-diagonal conditional observation covariance makes a

correlations that recursion does not remove. Include the counterexample: for
`y_k = h_k θ + ε_k + e_k` with independent priors `Var(θ)=p`, `Var(ε_k)=d_k`, `Var(e_k)=r_k`,

$$\operatorname{Cov}(\epsilon_i,\epsilon_j\mid y)=\frac{d_i d_j\, p\, h_i h_j}{s_i s_j\left(1+p\sum_l h_l^2/s_l\right)}\neq 0,\quad i\neq j,$$

directions. So "conditional on shaft angle" is **not** the filtered distribution an exact Kalman
recursion needs, and Woodbury on the initial `S` is insufficient to establish `O(K)`.
**Fix:** withdraw the claim. State that **candidate 1 uses no Kalman filter at all** — it uses

  remaining allowed rounds **simplifying** — one change per remaining round (remove or tie a
  component, or simplify the optimizer).
- **Failed simplifications never erase a passing incumbent.**
- **Thresholds are never moved to let a simpler model through.**
- Selection compares: explicit stochastic mechanisms, independent parameter blocks / degrees of
  freedom, latent states, and inference stages/approximations. Favour exact transitions, explicit
  finite-window kernels, ordinary well-understood optimization. Report **conceptual complexity**
  alongside numerical scores and runtime; a faster **opaque** approximation is not automatically
  simpler mathematically.
- The candidate sequence is adaptive to diagnostics: start simple, add one motivated complexity only
  when a named acceptance failure calls for it.

Write these as the documents' planted/validation list (they replace or subsume the existing lists;

   order-normalised differences; biased-carrier + bias/OU ambiguity **reported**, including the

5. Subwindow-oscillation finite-window line (D3), and **state-grid convergence** as `Δ_state`

6. Overlap duplicates create no exposure or information; no held-out raw-sample support leakage.
7. Generated physical RPS integrates to the shared phase, excludes `ε`, and has the same timeline
   and length as the audio after resampling.
8. Near-crossing behaviour uses joint complex observations and companion harmonics; no

   declared beforehand.
9. Finite parameter/device gradients.
10. If a sparse method is ever introduced: small-`K` sparse vs dense reference on objective and
    recovery — with **no** exact-`O(K)` assertion.

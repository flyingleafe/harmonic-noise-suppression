## 41. Exact candidate API — dispatch on THESE names

Confirmed by the candidate's owner as what is actually in the file.

**Export layout.** Top level: `schema_version` (1), `model_family` (`"shared_shaft_ou"`),
`rig_id`, `parameters`, `training_provenance`, `diagnostics`. **There is no
`summary['clips']`.** The clip list lives at `training_provenance['clips']`, each a dict of
`clip_id/dataset/recording/start_s/seconds/channels/rps_key/regime`. Rotor count comes from
`parameters['profile_db']` shape `(R, K)`. **If `model_family` is absent, it is a legacy
export** — that is your dispatch test.

**`RevisedRender`** (frozen dataclass, revised_phase.py 260-266, constructed 1882-1903),
returned by `render_revised`:

- `audio`: `(M, T)` float32 at `sample_rate`
- `physical_rps`: `(R, T)` realized interval-average shaft rev/s, exactly the audio's length and
  timeline, eps excluded
- `reference_rps`: `(R, T)` the raw telemetry reference **all arms share**, same length
- `sample_rate`: int
- `diagnostics`: dict (`eps_in_physical_rps=False`, `physical_rps_definition`,
  `reference_rps_definition`, `mean_abs_physical_minus_reference_rps`, `seed`, `rendered_orders`,
  lam/sigma/d_scalar, `bias_mean_hz`)

**Primary MAE is against `reference_rps`** (shared across all arms). `physical_rps` is the
**diagnostic only**. Do not swap them.

Signatures:

- `render_revised(export, rps, *, sample_rate=16000, sample_rate_native=44100, n_mics=8, seed=0) -> RevisedRender`.
  `rps` is `(R, T)` raw telemetry at `sample_rate`. Raises if `rps.shape[0]` mismatches the
  export's rotor count, or if the export carries fewer mics than `n_mics`.
- `predict_spectrum(export, clip, *, n_fft=16384, hop=1024, mode="prior") -> (M, N, F)` in
  `data.periodogram(clip, n_fft, hop).power` units and shape. **`mode="prior"` is the held-out
  path** (raw telemetry + learned bias mean, `m=0`, full prior OU+D kernel) and never touches
  clip audio. `mode="training_replay"` **raises** unless `clip.clip_id` is in
  `export["diagnostics"]["map_state"]` — never call it for a new clip.

Retain the legacy path **only** for baseline families. A shape-compatible file evaluated through
the wrong renderer/expected-periodogram law is a silent wrong answer, which is worse than the
current crash.

## 43. Separate the two level effects before naming either

Refining addendum 7 §38, from the candidate owner:

- `normalize_rms` rescales the **whole waveform**: it erases absolute level but leaves
  **line-to-floor ratios intact**.
- The `sqrt(native/sr)` effect moves the **floor relative to the tones**.

They are separable, so validate with a pure tone **and** the floor:

- tones match, floor ~4.4 dB low  -> the **sample-rate** effect;
- tones and floor offset together by a common factor -> **`normalize_rms`**.

Keep them apart and name each explicitly. Do not collapse both into one fudge factor.

## Motivation

The transfer test of the fitting campaign: SimpleConvV2 under the unified
regime on synthetic audio only, drawn 50/50 from the two rigs' **fitted**
presets (`conf/online_mix/rig_fitted_5050.yaml`, generated by
`experiments.stochastic_fit.run popexport` through the same
`raw_predictive.population_ranges` the posterior-predictive gate renders with).

Everything transferred here is measured on training recordings only (FLY125 /
dregon_room2): the decomposed-envelope profile hierarchy with one-standard-error
rank selection, the amplitude process (one OU component, std 2.90 dB, tau
0.82 s, cross-order coherence 0.191, selected by leave-one-rotor-out CV), the
line and floor speed laws (3.93 and 3.46 dB per dB rps, both previously pinned
at 2.5), per-microphone static line phase, and a static per-rotor
shaft-minus-label offset (robust scale 0.41 rev/s Michael's, 1.38 DREGON) so the
synthetic task carries the same label uncertainty the real task does.

Baselines: `real_r4_scv2_unified` (real data in training, best `val/real_r3`
2.99) and `rig_fm_scv2_unified` (the pre-fit hand-exported presets, 23.08 —
7.7x worse than R4).

Held-out predictive state of the Michael preset at submission: coverage 0.819
(bar 0.80, PASS), median curve IQR RMSE 0.444 (bar 1.0, PASS), classifier AUC
0.804 with bootstrap upper 0.904 (bar 0.80, FAIL). DREGON descriptive:
coverage 0.734, curve RMSE 1.80.
